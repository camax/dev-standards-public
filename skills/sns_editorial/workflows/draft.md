# 出力形式（固定フォーマット）

日記・過去ログを分析したら、最初に全媒体の判定サマリーを提示する：

```markdown
【X本垢】
判定：[採用 / スキップ推奨]
テーマ：
理由：

【Threads】
判定：[採用 / スキップ推奨]
テーマ：
理由：

【Instagram】
判定：[採用 / 条件付き採用 / スキップ推奨]
投稿形式：[単写真投稿 / カルーセル]
テーマ：
利用可能な本人撮影素材：
不足素材：
外部素材が必要か：
生成画像が必要か：
理由：

【Xビジネス】
判定：[採用 / スキップ推奨]
テーマ：
理由：
```

その後、**採用・条件付き採用になった媒体のみ** 投稿案を生成する。

### Instagram採用時の追加出力項目：
- 使用素材一覧
- 素材ごとの出典（本人撮影 / 公式素材 / 生成画像）
- 投稿形式（単写真 / カルーセル枚数）
- 画像構成（画像内容、文字入れの有無、画像内テキスト）
- キャプション
- 権利上の注意点
- 制作・生成した画像（生成画像がある場合）
