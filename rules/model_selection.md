# 🎚️ モデル選定・エスカレーション

Claude Code（`CLAUDE.md` の `@rules/model_selection.md`）と Codex / Antigravity
（`AGENTS.md` の常時適用ルール一覧）が共通で参照するモデル選定ルール。

すべての新規依頼について、作業開始前に依頼を「低・中・高・最高」の4段階で判定する。

最初の応答では、次の1行を必ず伝える。

`モデル判定：［低 / 中 / 高 / 最高］｜推奨：［モデル名・思考量］｜理由：［簡潔な理由］`

- 低・中：推奨モデルでそのまま作業を開始してよい。
- 高・最高：推奨モデル・思考量・理由を提示し、ユーザーの明示承認を得てから切り替えまたは作業開始する。
- ユーザーがモデルまたは思考量を明示指定した場合は、その指定を優先する。
- 高性能モデルを、単純な要約・整理・軽微な修正へ自動的に使わない。
- 重要設計、金融関連の調査、複数ファイルの大規模変更、外部影響や復元困難な変更は、原則として高または最高に判定する。
- モデル選定は、品質だけでなく、コスト・速度・失敗時の影響も踏まえて判断する。
