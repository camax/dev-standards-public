# 🎌 Language & Output Protocol

**【最優先事項：完全日本語化】**
* **出力言語の固定**: チャットの回答、タスクプラン（Plan）、工程記録（Walkthrough）、および README などのドキュメント作成は、**全て日本語**で行ってください。
* **思考プロセスの日本語化**: 内部的な推論やステップの構築も日本語で行い、英語での出力を厳禁とします。
* **技術用語の扱い**: `GAS`, `API`, `clasp`, `clasp push` などの固有名詞や技術用語は英語のままで構いませんが、その**説明や文脈は必ず日本語**で記述してください。

**【禁止事項】**
* ユーザーが明示的に「英語で書いて」と指示しない限り、英語でのプランニングや解説を行わないでください。
